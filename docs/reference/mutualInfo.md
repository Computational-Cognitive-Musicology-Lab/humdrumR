# Calculate Mutual Information of variables

Calculate Mutual Information of variables

## Usage

``` r
mutualInfo(x, ...)

# S4 method for probabilityDistribution
mutualInfo(x, ..., base = 2)

# S4 method for table
mutualInfo(x, base = 2, margin = NULL, na.rm = FALSE)

# S4 method for discrete
mutualInfo(x, ..., base = 2, na.rm = FALSE)
```
