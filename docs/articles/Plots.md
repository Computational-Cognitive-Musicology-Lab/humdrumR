# Making plots with humdrumR

Welcome to “Making plots with humdrum$`_{\mathbb{R}}`$”! This article
provides a quick introduction to the basics of plotting in R, but mostly
focuses on humdrum$`_{\mathbb{R}}`$’s own specialty plotting function,
[`draw()`](https://humdrumR.ccml.gtcmt.gatech.edu/reference/draw.md).
Our [`draw()`](https://humdrumR.ccml.gtcmt.gatech.edu/reference/draw.md)
function is not a full replacement for either of R’s main plotting
systems (base and \[ggplot\]\[ggplot2\]), but it is really useful.
